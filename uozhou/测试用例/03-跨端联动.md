# 跨端联动 - 手工测试用例

> 范围：商家端（后台 Web + 商家 App）和客户端（客户 App）同时在线，一端操作另一端能正确反映。重点验证 **后端状态机 + React Query 数据一致性 + 设置生效**。
> 测试人员：____
> 测试环境：参见 [00-测试用例总览.md](./00-测试用例总览.md)
>
> 工程提示（MVP 不做实时推送）：
> - 没有 WebSocket / SSE，"另一端能看到变化"指：被动端**手动下拉刷新** 或 **React Query 默认 `refetchOnWindowFocus`** 触发后能看到。
> - 用例步骤里凡是要求"另一端变化"的，都明确写"在另一端窗口手动刷新页面 / 切回该 Tab"，不要假定有推送。
> - 建议测试时打开两个 Chrome 窗口或两台设备：一个登录商家、一个登录客户。
