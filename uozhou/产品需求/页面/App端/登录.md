页面名称：登录页（login）

> MVP 版本：React Native (Expo) App 端实现
> 技术栈：Expo SDK 51+ + Expo Router (file-based) + TypeScript
> 状态管理：React Query (TanStack Query) for 服务端态；Zustand for 本地态（购物车、登录态）
> 表单：react-hook-form + zod（schema 来自 packages/types 生成产物）
> 样式：StyleSheet.create + 设计令牌（packages/shared/tokens）
> 鉴权：JWT 存 expo-secure-store，自动注入 Authorization header（axios interceptor）
> 网络：axios + Orval 生成 client（packages/api-client）
> 字体：Expo Font，加载 system fallback

基本信息
页面ID：login_001

入口：App 首次启动 / 退出登录后 / token 失效后自动 `router.replace('/login')`

状态：正常 / 加载中（提交按钮 loading）/ 异常（网络错误，错误条展示）

文件路径建议：`app/login.tsx`（Expo Router 文件路由）

元素清单（带ID）
1. 手机号输入区（login-phone-001）
手机号输入框（login-phone-input-001）：占位「请输入手机号」，键盘类型数字，最多11位
- **RN 实现**：`<TextInput keyboardType="number-pad" maxLength={11} placeholder="请输入手机号" />`，配合 react-hook-form 的 `Controller` 接管 `value/onChangeText`

国家/地区代码（login-country-code-001）：**MVP 砍除**，默认硬编码 +86，不展示下拉

2. 验证码区（login-code-001）
验证码输入框（login-code-input-001）：占位「请输入验证码」，6位数字
- **RN 实现**：`<TextInput keyboardType="number-pad" maxLength={6} placeholder="请输入验证码" />`

获取验证码按钮（login-get-code-001）：文字「获取验证码」，倒计时 60 秒
- **RN 实现**：使用 `<Pressable>`，倒计时用 `useEffect` + `useRef` 持有 `setInterval` 句柄，组件卸载时 `clearInterval`。倒计时状态显示「%d秒后重试」并 `disabled`

3. 协议勾选区（login-agreement-001）
复选框（login-agree-check-001）：默认未勾选
- **RN 实现**：自封装 `<Checkbox checked={agree} onPress={() => setAgree(v=>!v)} />`，内部用 `<Pressable>` + 图标切换

协议文本（login-agree-text-001）：「我已阅读并同意《用户协议》和《隐私政策》」
- **RN 实现**：用 `<Text>` 组合：协议名用嵌套 `<Text onPress={...}>` 实现可点击，颜色用 token `colors.link`

4. 登录按钮（login-submit-btn-001）
主要按钮，文字「登录 / 注册」
- **RN 实现**：自封装 `<PrimaryButton loading={isPending} disabled={!canSubmit} />`，loading 时内部显示 `<ActivityIndicator />`

5. 第三方登录区（login-social-001）
**MVP 砍除**：登录页隐藏微信图标，整块不渲染

6. 错误提示条（login-error-tip-001）
红色背景短条，自动消失（3 秒）
- **RN 实现**：使用全局 Toast Context 或 `react-native-root-toast`；条件渲染时用 `<Animated.View>` 做淡入淡出

交互逻辑
A. 获取验证码（login-interaction-get-code-001）
触发：点击「获取验证码」按钮

前置：手机号非空且格式正确（11位数字，正则 `/^1[3-9]\d{9}$/`）

行为：调用 `POST /api/sms/code` → 成功：按钮进入 60 秒倒计时，禁用，Toast「验证码已发送」；失败：Toast 错误原因，按钮恢复
- **RN 代码**：
  ```ts
  const { mutate: sendCode, isPending } = useSendSmsCodeMutation();
  const onGetCode = () => {
    if (!/^1[3-9]\d{9}$/.test(phone)) return Toast.show('请输入正确的手机号');
    sendCode({ phone }, {
      onSuccess: (data) => {
        startCountdown(60);
        // 开发环境后端会返回 _code 字段方便调试，生产环境靠真实短信
        if (__DEV__ && data._code) console.log('[DEV] code =', data._code);
        Toast.show('验证码已发送');
      },
      onError: (e) => Toast.show(e.message ?? '发送失败'),
    });
  };
  ```

B. 登录/注册（login-interaction-submit-001）
触发：点击「登录 / 注册」按钮

前置：手机号、验证码非空，协议已勾选

行为：调用 `POST /api/auth/login`（手机号+验证码）→ 按钮显示 loading → 成功：后端返回用户信息（含 role）、access token、refresh token → 分别存储 → 根据 role 跳转对应首页（`role='staff'` → `/staff/workbench`；`role='customer'` → `/customer/home`）；失败：Toast 错误信息（如「验证码错误」），按钮恢复
- **RN 代码**：
  ```ts
  import * as SecureStore from 'expo-secure-store';
  import AsyncStorage from '@react-native-async-storage/async-storage';
  import { router } from 'expo-router';

  const { mutate, isPending } = useLoginMutation();
  const onSubmit = handleSubmit(({ phone, code }) => {
    mutate({ phone, code }, {
      onSuccess: async (data) => {
        // access / refresh token 走 SecureStore（敏感）
        await SecureStore.setItemAsync('access_token', data.accessToken);
        await SecureStore.setItemAsync('refresh_token', data.refreshToken);
        // user 信息走 AsyncStorage（非敏感，方便冷启动展示）
        await AsyncStorage.setItem('user', JSON.stringify(data.user));
        useAuthStore.getState().setUser(data.user);
        router.replace(data.user.role === 'staff' ? '/staff/workbench' : '/customer/home');
      },
      onError: (e) => Toast.show(e.message ?? '登录失败'),
    });
  });
  ```

C. 协议链接跳转（login-interaction-policy-001）
触发：点击协议文本中的《用户协议》或《隐私政策》

行为：**MVP 砍除内嵌 WebView**。改为 `expo-web-browser` 打开外链：
- **RN 代码**：

  ```ts
  WebBrowser.openBrowserAsync('https://example.com/terms');
  ```
