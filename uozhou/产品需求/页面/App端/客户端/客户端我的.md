页面名称：客户端我的（customer_me）

> MVP 版本：RN App（仅显示昵称 + 手机号脱敏 + 退出登录；不做地址 / 帮助 / 反馈 / 版本 / 头像更换）
> 技术栈：Expo SDK 51+ + Expo Router (file-based) + TypeScript
> 状态管理：React Query for 服务端态；Zustand for 本地态（购物车持久化到 AsyncStorage）
> 表单：react-hook-form + zod
> 样式：StyleSheet.create + 设计令牌
> 鉴权：JWT 存 expo-secure-store，axios interceptor 注入 Authorization
> 网络：axios + Orval 生成 client
> 图片：expo-image

交互逻辑

A. 退出登录（cust-me-logout）
触发：点击退出登录

行为：
1. `Alert.alert` 二次确认「确定退出当前账号吗？」
2. 确认后：
   - 删除 `expo-secure-store` 的 `access_token` / `refresh_token`
   - 删除 `AsyncStorage` 的 `user` / `cart`（购物车 Zustand 的 persist key）
   - `queryClient.clear()` 清掉所有缓存
   - `router.replace('/login')`（**用 replace，禁止用户后退回到登录前的页面**）
  - **RN 代码**：
    ```ts
    Alert.alert('退出登录', '确定退出当前账号吗？', [
      { text: '取消', style: 'cancel' },
      { text: '确定退出', style: 'destructive', onPress: async () => {
        await Promise.all([
          SecureStore.deleteItemAsync('access_token'),
          SecureStore.deleteItemAsync('refresh_token'),
          AsyncStorage.multiRemove(['user', 'cart']),
        ]);
        queryClient.clear();
        useCartStore.getState().clear();
        router.replace('/login');
      }},
    ]);
    ```
