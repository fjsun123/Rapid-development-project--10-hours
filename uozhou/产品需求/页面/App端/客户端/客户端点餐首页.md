页面名称：客户端点餐首页（customer_home）

> MVP 版本：RN App（客户端点餐入口，单门店、无切换门店、无备注、单列 FlatList）
> 技术栈：Expo SDK 51+ + Expo Router (file-based) + TypeScript
> 状态管理：React Query for 服务端态；Zustand for 本地态（购物车持久化到 AsyncStorage）
> 表单：react-hook-form + zod
> 样式：StyleSheet.create + 设计令牌
> 鉴权：JWT 存 expo-secure-store，axios interceptor 注入 Authorization
> 网络：axios + Orval 生成 client
> 图片：expo-image

基本信息
页面ID：customer_home_001

入口：底部 Tab「点餐」（仅 role='customer' 时显示）

路由：`/(customer)/home`（Expo Router file-based，`app/(customer)/home.tsx`）

状态：正常 / 加载（骨架屏）/ 空态（无菜品）/ 异常（带 Retry 按钮）

元素清单（带ID）

1. 门店信息栏（cust-home-store-001）
门店名称（cust-home-store-name-001）：显示当前用餐门店（MVP 写死单门店，文案从 `EXPO_PUBLIC_STORE_NAME` 或常量读取）

营业状态标识（cust-home-store-status-001）：绿色圆点 +「营业中」或灰色「已打烊」
  - **RN 实现**：圆点用 `<View style={{ width: 8, height: 8, borderRadius: 4, backgroundColor: open ? '#22C55E' : '#9CA3AF' }} />`

2. 分类 Tab（cust-home-category-tabs-001）
横向滚动，显示所有菜品分类（由前端从菜品列表 `groupBy(categoryName)` 自行聚合得出）

当前选中高亮，下方指示条
  - **RN 实现**：`<ScrollView horizontal showsHorizontalScrollIndicator={false}>` + `<Pressable>` 列表项；不要用 `react-native-tab-view`（杀鸡用牛刀，且本页 Tab 切换只是滚定位/筛选，并非切页）

3. 菜品列表（单列 FlatList，cust-home-menu-list-001）
菜品卡片（cust-home-menu-card-001）：图片（`expo-image`，宽 96dp、圆角 8dp）、名称、价格、加减按钮

若菜品 `available=false` 或 `stock<=0`，卡片置灰（`opacity: 0.5`），显示「售罄」标签，加减按钮 `disabled`
  - **RN 实现**：`<FlatList data={items} renderItem={...} keyExtractor={i => String(i.id)} />`，配 `<RefreshControl refreshing={isRefetching} onRefresh={refetch} />`
  - **不做双列瀑布流**（MVP 砍）

4. 悬浮购物车（cust-home-cart-fab-001）
圆形按钮（直径 56dp），购物车图标 + 角标（总商品数量） + 总金额（¥）

点击打开购物车 Modal
  - **RN 实现**：包一层 `<View pointerEvents="box-none" style={StyleSheet.absoluteFill}>`，里面放 `<Pressable style={{ position: 'absolute', right: 16, bottom: 24 + insets.bottom }}>`；`insets` 来自 `useSafeAreaInsets()`

5. 购物车 Modal（cust-home-cart-modal-001，替代原"右侧抽屉"）
RN `<Modal animationType="slide" transparent>` 从底部升起；遮罩 `<Pressable onPress={close} style={{flex:1, backgroundColor:'rgba(0,0,0,0.4)'}}>`

已点菜品列表（名称、单价、数量、小计，支持加减/删除）

去结算按钮（固定在 Modal 底部，留 `safeAreaInsets.bottom` 间距）
  - **不做整单备注**（MVP 砍）
  - **不做右侧滑出抽屉**（RN 自实现成本高，MVP 用底部 Modal 替代）

6. 加载骨架屏（cust-home-skeleton-001）
顶部分类 Tab 骨架 + 菜品卡片骨架（4～6个）
  - **RN 实现**：`react-content-loader` 的 RN 版（`react-content-loader/native`），或简单用灰色 `<View>` + `react-native-reanimated` 做闪烁

7. 空状态（cust-home-empty-001）
当某分类下无菜品时显示「暂无菜品」
  - **RN 实现**：`<FlatList ListEmptyComponent={<Empty />} />`

交互逻辑

A. 分类切换（cust-home-category-switch）
触发：点击某个分类 Tab

行为：本地切换选中分类 → 从同一份 `menu-items` 数据中 filter 出该分类的菜品；**不再每次请求接口**（数据一次拉全，本地分组、本地切换）
  - **RN 代码**：
    ```ts
    const { data: items = [] } = useQuery({
      queryKey: ['menu-items'],
      queryFn: () => api.get('/api/menu-items').then(r => r.data),
      staleTime: 60_000,
    });
    const categories = useMemo(
      () => Array.from(new Set(items.map(i => i.categoryName))),
      [items]
    );
    const visible = useMemo(
      () => items.filter(i => i.categoryName === activeCategory),
      [items, activeCategory]
    );
    ```

B. 添加/减少菜品（cust-home-update-cart）
触发：点击菜品卡片的「+」或「-」按钮

行为：
- 加菜：数量+1，更新 Zustand 购物车 → 自动 persist 到 AsyncStorage，悬浮按钮角标/总金额自动响应
- 减菜：数量>1 则 -1；数量==1 则移除该菜品
- 售罄或 `stock <= 已选数量` 时，加号 `disabled`；超限点击 toast「库存不足」

购物车数据**不立即提交后端**，仅在「去结算」时创建订单
  - **RN 代码**：
    ```ts
    const { addItem, decItem } = useCartStore();
    <Pressable onPress={() => addItem(menuItem)} disabled={!menuItem.available || menuItem.stock <= 0} />
    ```

C. 打开购物车 Modal（cust-home-open-cart）
触发：点击悬浮购物车按钮

前置：购物车非空时才打开（空购物车按钮点击 toast「购物车为空」）

行为：`setCartVisible(true)`，Modal 从底部升起

D. 修改购物车内菜品（cust-home-cart-modify）
触发：在购物车 Modal 内修改数量或删除

行为：实时调用 `useCartStore` 的 `addItem/decItem/removeItem`，UI 通过 selector 自动响应；总金额变化时悬浮按钮同步刷新

E. 去结算（cust-home-checkout）
触发：点击购物车 Modal 内的「去结算」

前置：购物车非空

行为：`router.push('/(customer)/confirm-order')`，确认订单页从 `useCartStore()` 读取数据，无需透传 params

购物车 Store 草图（Zustand + persist）
```ts
// src/stores/cart.ts
import { create } from 'zustand';
import { persist, createJSONStorage } from 'zustand/middleware';
import AsyncStorage from '@react-native-async-storage/async-storage';

type CartItem = { id: number; name: string; price: number; qty: number };
type CartState = {
  items: CartItem[];
  addItem: (m: { id: number; name: string; price: number }) => void;
  decItem: (id: number) => void;
  removeItem: (id: number) => void;
  clear: () => void;
};
export const useCartStore = create<CartState>()(
  persist(
    (set) => ({
      items: [],
      addItem: (m) => set((s) => {
        const ex = s.items.find(i => i.id === m.id);
        return ex
          ? { items: s.items.map(i => i.id === m.id ? { ...i, qty: i.qty + 1 } : i) }
          : { items: [...s.items, { ...m, qty: 1 }] };
      }),
      decItem: (id) => set((s) => ({
        items: s.items.flatMap(i =>
          i.id !== id ? [i] : i.qty > 1 ? [{ ...i, qty: i.qty - 1 }] : []
        ),
      })),
      removeItem: (id) => set((s) => ({ items: s.items.filter(i => i.id !== id) })),
      clear: () => set({ items: [] }),
    }),
    { name: 'cart', storage: createJSONStorage(() => AsyncStorage) }
  )
);
```
