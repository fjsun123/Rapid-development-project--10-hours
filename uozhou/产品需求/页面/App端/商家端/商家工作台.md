页面名称：商家工作台（staff_workbench）

> MVP 版本：React Native (Expo) App 端实现（商家端）
> 技术栈：Expo SDK 51+ + Expo Router (file-based) + TypeScript
> 状态管理：React Query (TanStack Query) for 服务端态；Zustand for 本地态（购物车、登录态）
> 表单：react-hook-form + zod（schema 来自 packages/types 生成产物）
> 样式：StyleSheet.create + 设计令牌（packages/shared/tokens）
> 鉴权：JWT 存 expo-secure-store，自动注入 Authorization header（axios interceptor）
> 网络：axios + Orval 生成 client（packages/api-client）
> 字体：Expo Font，加载 system fallback

基本信息
页面ID：staff_workbench_001

入口：底部 Tab「工作台」（仅 `user.role === 'staff'` 时显示该 Tab；进入受 `app/(staff)/_layout.tsx` 守卫）

角色状态：**MVP 不区分子角色**（不实现服务员/后厨/店长切换），所有 staff 看同一份工作台

补充：订单状态机操作（在订单详情页用到，但 API 在此列出供参考）
- 实际后端是 4 个独立端点（**不是** `PATCH /api/orders/:id/status`）：
  - `POST /api/orders/:id/confirm` 商家接单：pending → confirmed
  - `POST /api/orders/:id/ready` 出餐：confirmed → ready
  - `POST /api/orders/:id/complete` 完成：ready → completed
  - `POST /api/orders/:id/cancel` 取消（body: `{ reason }`）
