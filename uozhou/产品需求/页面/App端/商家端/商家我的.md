页面名称：商家我的（staff_me）

> MVP 版本：RN App（商家端）极简版「我的」页。本 MD 是 React Native / Expo 落地说明。仅保留「昵称 + 手机号 + 退出登录」三块。

> 技术栈：Expo SDK 51+ + Expo Router (file-based) + TypeScript
> 状态管理：React Query for 服务端态；Zustand for 本地态
> 表单：react-hook-form + zod
> 样式：StyleSheet.create + 设计令牌
> 鉴权：JWT 存 expo-secure-store，axios interceptor 注入 Authorization
> 网络：axios + Orval 生成 client

交互逻辑

A. 页面加载（staff-me-load）
触发：进入页面 / Tab focus

行为：`GET /api/user/profile` 拉取当前登录员工的昵称和手机号

- **RN 代码**：
```ts
const { data: me, isPending } = useQuery({
  queryKey: ['me'],
  queryFn: () => api.getProfile(),
  staleTime: 5 * 60 * 1000,
});
```

B. 退出登录（staff-me-logout）
触发：点击「退出登录」

行为：弹出二次确认对话框「确定退出当前账号吗？」→ 确认后：
1. 清除 `expo-secure-store` 的 `access_token` 和 `refresh_token`
2. 清除 `AsyncStorage` 的 `user` 缓存
3. 清空 React Query 缓存
4. `router.replace('/login')`

- **RN 代码**：
```ts
import * as SecureStore from 'expo-secure-store';
import AsyncStorage from '@react-native-async-storage/async-storage';
import { router } from 'expo-router';

const handleLogout = () => {
  Alert.alert('确定退出当前账号吗？', '', [
    { text: '取消', style: 'cancel' },
    {
      text: '确认退出',
      style: 'destructive',
      onPress: async () => {
        await Promise.all([
          SecureStore.deleteItemAsync('access_token'),
          SecureStore.deleteItemAsync('refresh_token'),
          AsyncStorage.removeItem('user'),
        ]);
        queryClient.clear();
        router.replace('/login');
      },
    },
  ]);
};
```

> 说明：后端没有强制的 `POST /api/auth/logout`，前端本地清 token 即视为已登出；如后续需要后端登出（黑名单 token），再补 mutation。

关联文档
路由：`/(staff)/me`（Expo Router file-based）

接口：

- `GET /api/user/profile` 拉取昵称 / 手机号

> 鉴权：axios interceptor 从 `expo-secure-store` 读 `access_token` 注入 `Authorization: Bearer <token>` 头。
> 退出登录纯前端：清 `expo-secure-store`（access_token / refresh_token）+ 清 `AsyncStorage`（user）→ `router.replace('/login')`，不调后端。
