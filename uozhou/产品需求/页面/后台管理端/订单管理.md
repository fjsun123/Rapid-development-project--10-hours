# 页面名称：后台订单管理（admin_orders）

> MVP 版本：保留筛选、创建订单、详情抽屉、状态机更新；砍掉自定义日期范围、分页器、状态时间线、状态更新二次确认对话框（仅取消订单保留二次确认）。

## 基本信息
- 页面ID：admin_orders_001
- 入口：左侧导航「订单」菜单，路由 /orders
- 状态：正常 / 加载（骨架屏）/ 空态 / 异常

## 元素清单（带ID）

### 1. 筛选区（admin-filter-section-001）
- 订单状态下拉（admin-filter-status-001）：多选，选项：待接单、制作中、待出餐、已完成、已取消
- 日期范围快捷按钮（admin-filter-date-001）：「今天」「本周」两个预设（互斥单选，可清除）
- 搜索框（admin-filter-search-001）：占位「搜索订单号或客户名」，支持实时搜索（防抖500ms）
- 重置按钮（admin-filter-reset-001）：文字按钮，清空所有筛选条件
- 创建订单按钮（admin-create-order-btn-001）：主要按钮，右上角

### 2. 订单表格（admin-orders-table-001）
列定义：
- 订单号（admin-table-order-no-001）：文字，可点击打开详情抽屉
- 客户（admin-table-customer-001）：客户姓名
- 总金额（admin-table-amount-001）：格式 ¥XX.XX
- 状态（admin-table-status-001）：状态徽章
  - pending = 黄色「待接单」
  - confirmed = 蓝色「制作中」
  - ready = 绿色「待出餐」
  - completed = 灰色「已完成」
  - cancelled = 红色「已取消」
- 创建时间（admin-table-created-at-001）：格式 YYYY-MM-DD HH:mm
- 操作列（admin-table-actions-001）：查看详情、更新状态

数据加载：固定取前 50 条（接口保留 page/size 入参，前端 MVP 不分页）。

### 3. 创建订单模态框（admin-create-order-modal-001）
分步骤表单：

**步骤1：选择客户（admin-modal-step1-001）**
- 客户下拉搜索（admin-modal-customer-select-001）：搜索现有客户
- 新增客户按钮（admin-modal-add-customer-001）：弹出短表单
- 新增客户表单：
  - 姓名输入框（必填）
  - 手机号输入框（必填）

**步骤2：添加菜品（admin-modal-step2-001）**
- 分类Tab（admin-modal-category-tabs-001）：水平滚动
- 菜品列表（admin-modal-menu-list-001）：按分类展示可用菜品
  - 菜品行：名称、单价、数量输入框、小计
- 右侧实时显示已添加菜品列表
- 底部显示合计金额（只读，前端预览；最终金额服务端计算）

**步骤3：确认订单（admin-modal-step3-001）**
- 客户信息确认
- 菜品列表确认
- 备注输入框（可选）
- 总金额显示

底部按钮：上一步、取消、提交订单

### 4. 订单详情抽屉（admin-order-drawer-001）
从右侧滑出，宽度 560px

内容：
- 订单基本信息（admin-drawer-info-001）
  - 订单号、状态徽章、下单时间、客户信息、备注
- 菜品明细表格（admin-drawer-items-001）
  - 列：菜品名称、单价、数量、小计
  - 底部合计行
- 状态操作区（admin-drawer-actions-001）
  - 动态显示可执行操作按钮（由后端 `/api/orders/:id/available-status` 返回）
  - pending：接单、取消
  - confirmed：出餐、取消
  - ready：完成

### 5. 取消订单确认对话框（admin-cancel-dialog-001）
- 仅取消操作弹出
- 文案：「确定取消该订单吗？取消后不可恢复，已扣减库存将归还。」
- 按钮：再想想 / 确定取消（红色）

### 6. 空状态（admin-orders-empty-001）
- 插图
- 文案「没有找到订单，试试清除筛选条件」
- 清除筛选按钮

### 7. 加载骨架屏（admin-orders-skeleton-001）
- 筛选区占位
- 表格骨架：10行

## 交互逻辑

### A. 筛选订单（admin-filter-orders）
触发：选择状态下拉 / 选择日期快捷按钮 / 输入搜索框

行为：
- 调用 GET /api/orders?status=xxx&dateFrom=xxx&dateTo=xxx&keyword=xxx&page=1&size=50
- 显示表格加载状态
- 成功：渲染订单列表
- 空结果：显示空状态

### B. 创建订单（admin-create-order）
触发：点击「创建订单」按钮

行为：
- 打开创建订单模态框
- 步骤1：选择或新增客户
  - 调用 GET /api/customers?keyword=xxx 搜索客户
  - 点击新增：调用 POST /api/customers
- 步骤2：添加菜品
  - 调用 GET /api/menu-items?available=true 获取可用菜品
  - 数量变更时实时计算小计
- 步骤3：确认提交
  - 调用 POST /api/orders
  - 成功：吐司「订单创建成功」，关闭模态框，刷新列表
  - 失败：
    - 菜品不可用：吐司「部分菜品已下架或库存不足」
    - 其他错误：吐司错误信息

### C. 查看订单详情（admin-view-order-detail）
触发：点击订单号或「查看详情」按钮

行为：
- 打开订单详情抽屉
- 调用 GET /api/orders/:id
- 调用 GET /api/orders/:id/available-status
- 渲染详情内容

### D. 更新订单状态（admin-update-order-status）
触发：在详情抽屉或表格操作列点击状态更新按钮

行为：
- 非取消操作：直接调用 PATCH /api/orders/:id/status，请求体 { status: targetStatus }
- 取消操作：弹出 admin-cancel-dialog-001 确认
- 按钮 loading
- 成功：吐司「订单状态已更新」，刷新列表和详情抽屉
- 失败：吐司错误原因（如「非法的状态转换」）
