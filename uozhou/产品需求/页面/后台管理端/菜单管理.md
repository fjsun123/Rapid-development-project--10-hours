# 页面名称：后台菜单管理（admin_menu）

> MVP 版本：保留分类 CRUD、菜品 CRUD、上下架开关、删除二次确认；砍掉批量上下架/删除、分类拖拽排序、上下架乐观更新、分页器、菜品多选复选框。

## 基本信息
- 页面ID：admin_menu_001
- 入口：左侧导航「菜单」菜单，路由 /menu
- 状态：正常 / 加载（骨架屏）/ 空态 / 异常

## 元素清单（带ID）

### 1. 左侧分类区（admin-menu-category-section-001）
- 分类标题（admin-menu-category-title-001）：文字「菜品分类」
- 新增分类按钮（admin-menu-add-category-btn-001）：文字按钮「+ 新增分类」
- 分类列表（admin-menu-category-list-001）
  - 分类项（admin-menu-category-item-001）：名称 + 菜品数量角标
  - 选中状态：背景色高亮
  - 操作按钮（admin-menu-category-actions-001）：编辑、删除（悬浮显示）
  - 排序：按 sortOrder 字段升序展示（修改 sortOrder 通过编辑模态完成，无拖拽）

### 2. 右侧菜品管理区（admin-menu-item-section-001）
- 顶部操作栏（admin-menu-toolbar-001）
  - 当前分类名（admin-menu-current-category-001）：面包屑显示
  - 新增菜品按钮（admin-menu-add-item-btn-001）：主要按钮

- 菜品表格（admin-menu-item-table-001）
  列定义：
  - 图片（admin-menu-table-image-001）：缩略图 64×64px，无图显示占位
  - 名称（admin-menu-table-name-001）：菜品名称
  - 分类（admin-menu-table-category-001）：所属分类标签
  - 售价（admin-menu-table-price-001）：格式 ¥XX.XX
  - 库存（admin-menu-table-stock-001）：数字，-1显示「不限」
  - 上架状态（admin-menu-table-status-001）：开关组件（非乐观更新，等待接口响应）
  - 操作列（admin-menu-table-actions-001）：编辑、删除

  数据加载：固定取当前分类下前 50 条（接口保留 page/size 入参，前端 MVP 不分页）。

### 3. 新增/编辑分类模态框（admin-menu-category-modal-001）
表单字段：
- 分类名称输入框（admin-menu-modal-category-name-001）：必填，最大10字符
- 排序权重输入框（admin-menu-modal-category-sort-001）：数字，默认0，越大越靠前

### 4. 新增/编辑菜品模态框（admin-menu-item-modal-001）
表单字段：
- 菜品名称输入框（admin-menu-modal-item-name-001）：必填，最大30字符
- 分类下拉选择（admin-menu-modal-item-category-001）：必填，单选
- 售价输入框（admin-menu-modal-item-price-001）：必填，正整数，单位：分（前端显示元）
- 库存输入框（admin-menu-modal-item-stock-001）：非负整数，-1表示不限
- 描述输入框（admin-menu-modal-item-desc-001）：可选，多行文本，最大200字符
- 图片URL输入框（admin-menu-modal-item-image-001）：可选，支持图片预览（无上传功能，仅填 URL，种子数据使用 placehold.co 占位）
- 上架状态开关（admin-menu-modal-item-available-001）：默认开启

### 5. 删除菜品确认对话框（admin-menu-delete-dialog-001）
- 文案：「确定删除该菜品吗？删除后不可恢复。」
- 按钮：取消 / 确定删除（红色）

### 6. 删除分类确认对话框（admin-menu-delete-category-dialog-001）
- 文案：「确定删除该分类吗？」
- 按钮：取消 / 确定删除（红色）
- 如分类下存在菜品则后端拒绝，吐司提示

### 7. 空状态（admin-menu-empty-001）
- 插图
- 文案「此分类下暂无菜品，点击新增菜品」
- 新增菜品按钮

### 8. 加载骨架屏（admin-menu-skeleton-001）
- 左侧分类列表骨架：3~5个分类项
- 右侧表格骨架：5行

## 交互逻辑

### A. 选择分类（admin-menu-select-category）
触发：点击左侧分类项

行为：
- 更新选中状态（高亮背景）
- 调用 GET /api/menu-items?categoryId=xxx&page=1&size=50
- 刷新右侧菜品表格
- 更新面包屑显示当前分类名

### B. 新增分类（admin-menu-add-category）
触发：点击「新增分类」按钮

行为：
- 打开新增分类模态框
- 提交时调用 POST /api/categories
- 成功：吐司「分类添加成功」，关闭模态框，刷新分类列表
- 失败：吐司错误信息

### C. 编辑分类（admin-menu-edit-category）
触发：悬浮在分类项上，点击编辑按钮

行为：
- 打开编辑分类模态框，预填当前分类信息
- 提交时调用 PATCH /api/categories/:id
- 成功：吐司「分类已更新」，关闭模态框，刷新分类列表
- 失败：吐司错误信息

### D. 删除分类（admin-menu-delete-category）
触发：悬浮在分类项上，点击删除按钮

行为：
- 弹出确认对话框
- 确认后调用 DELETE /api/categories/:id
- 成功：吐司「分类已删除」，刷新分类列表
- 失败：吐司「该分类下存在菜品，无法删除」

### E. 新增菜品（admin-menu-add-item）
触发：点击「新增菜品」按钮

行为：
- 打开新增菜品模态框，分类默认选中当前分类
- 提交时前端校验后调用 POST /api/menu-items
- 成功：吐司「菜品添加成功」，关闭模态框，刷新表格
- 失败：吐司错误信息

### F. 编辑菜品（admin-menu-edit-item）
触发：点击表格操作列「编辑」按钮

行为：
- 打开编辑菜品模态框，预填当前菜品信息
- 提交时调用 PATCH /api/menu-items/:id
- 成功：吐司「菜品信息已更新」，刷新表格
- 失败：吐司错误信息

### G. 删除菜品（admin-menu-delete-item）
触发：点击表格操作列「删除」按钮

行为：
- 弹出确认对话框
- 确认后调用 DELETE /api/menu-items/:id
- 成功：吐司「菜品已删除」，刷新表格
- 失败：吐司「该菜品存在未完成订单，无法删除」

### H. 上架/下架状态切换（admin-menu-toggle-status）
触发：点击表格状态列开关

行为：
- 开关进入 loading 态（禁用、显示菊花）
- 调用 PATCH /api/menu-items/:id（仅传 available 字段）
- 成功：UI 切换到新状态，吐司「菜品已上架」或「菜品已下架」
- 失败：保持原状态，吐司错误信息
- 注：MVP 不做乐观更新，等待接口响应后再变更 UI

## 数值常量

- 列表最大显示条数（MVP 不分页）：50条
- 分类名称最大长度：10字符
- 菜品名称最大长度：30字符
- 描述最大长度：200字符
- 缩略图尺寸：64×64px
- 售价单位：分（前端显示为元）
- 库存-1表示不限

## 关联文档

- 路由：/menu
- 接口：
  - GET /api/categories
  - POST /api/categories
  - PATCH /api/categories/:id
  - DELETE /api/categories/:id
  - GET /api/menu-items（支持 categoryId, page, size, available）
  - POST /api/menu-items
  - PATCH /api/menu-items/:id
  - DELETE /api/menu-items/:id
- 埋点：admin_menu_view, admin_menu_select_category, admin_menu_add_category, admin_menu_edit_category, admin_menu_delete_category, admin_menu_add_item, admin_menu_edit_item, admin_menu_delete_item, admin_menu_toggle_status
- 权限：需登录
